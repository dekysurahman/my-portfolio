# Deky Surahman Portfolio

A modern, responsive resume and portfolio page for Deky Surahman.

## Run locally

Open `index.html` in a browser, or serve the project with any static file server.

The page uses semantic HTML and plain CSS so the content remains easy to read for ATS parsers and straightforward to extend with project details later. The recruiter-facing download button serves `cv/CV_DekySurahman.pdf`.
